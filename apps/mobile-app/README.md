# UniApp User Flow

The page source follows the UniApp page structure (`src/pages/index/index.vue`, `pages.json`, and `manifest.json`) and uses the same local Java API contract as the intended mobile runtime.

Commands:

- `npm run build`: verified browser H5 preview build for the showcase environment.
- `npm run build:uni`: official UniApp compiler entry. Verified locally on 2026-07-25 with the Vue 3 compatibility alias used by this showcase.

The H5 preview is not a substitute claim for Android/iOS packaging.
