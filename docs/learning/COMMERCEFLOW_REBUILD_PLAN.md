# CommerceFlow Learning Rebuild Plan

The later `commerceflow-learning-rebuild` is a separate learning repository and is not created by P7A.

1. Rebuild a small Java catalog with interfaces, collections, exceptions, BigDecimal, Maven, JUnit, and debugger checkpoints.
2. Rebuild the order core: request validation, item aggregation, atomic stock update, transaction, snapshots, and idempotency.
3. Rebuild a limited evidence read model and explain JDBC versus MyBatis choice.
4. Rebuild the Java-to-Python contract using deterministic facts only; then add Java fallback and Trace.
5. Rebuild a minimal Redis limiter only after explaining the Lua atomicity and 429 user experience.
6. Rebuild one Vue view and one UniApp H5 flow from wire-level contracts, not copied components.

Each feature must use `docs/evidence/Px-phase/feature/` with learner-written code, commands, tests, debugger observations, changed requirement, closed-book explanation, and remaining questions.
