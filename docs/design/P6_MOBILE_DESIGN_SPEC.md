# P6 移动端设计规格

## 参考边界

已有 `docs/design_refs/generated/07-mobile-product-detail-reference-v1.png` 与 `08-mobile-order-flow-reference-v1.png` 只提供布局和信息层级参考，不是运行证据。正式截图必须来自真实 H5/UniApp 页面、真实 API 和本地 Flyway 数据；不把参考图作为背景，不生成新图，不使用第三方商品图。

## 页面与状态

| 页面 | 必须真实展示 | 状态 |
| --- | --- | --- |
| 商品列表 | 图片、名称、分类、起始价或真实价格、可售/缺货信号 | loading、empty、error、retry、图片失败 |
| 商品详情 | 商品图、描述、SKU 颜色/尺寸、价格、币种、库存、购买按钮 | SKU 切换、缺货禁用、网络错误、返回后刷新 |
| SKU 选择 | 当前选择、完整可选项、库存和价格 | 不把未选状态误写成已选；选择后更新图片/价格 |
| 购物车 | 服务端 cart item、真实数量、价格、库存 | 空购物车、读取失败、库存变化 |
| 确认订单 | 商品/SKU快照、数量、金额、币种、提交按钮 | 提交中、库存不足、相同 Key 重放、不同请求体 409 |
| 下单成功 | 真实 orderNo、金额、币种、`CREATED/已创建` | 不显示支付、发货、物流、完成 |
| 订单列表/详情 | 真实 orderNo、时间、商品快照、金额和 CREATED | loading、empty、error、retry |
| AI 商品客服 | 当前商品/SKU上下文、问题、结构化回答建议 | loading、空回答、服务不可用、429、FAIL_OPEN |

## 视觉方向

使用现有移动参考的轻量商品展示感，但以 CommerceFlow 真实数据为核心：白色商品图底、浅灰/暖白背景、清晰蓝色操作、青绿色正常库存、橙色低库存、红色缺货。底部固定操作区必须避开 `--window-bottom`/安全区域。长商品名、SKU 编码和错误消息要换行，不允许横向溢出。

## 禁止展示

不展示注册、支付、物流、退款、地址、优惠券、积分、会员、虚假库存、虚构订单状态、AI 历史、伪造 trace 或网络图片。商品图只能来自当前项目已有正式本地素材和真实 API 返回的路径。
