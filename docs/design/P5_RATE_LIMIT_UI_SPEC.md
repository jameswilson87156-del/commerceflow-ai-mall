# P5 限流前端规格

P5B 在已有 AI 客服工作台上增加真实可用的限流反馈，不新增业务功能。

- 正常成功后显示“本窗口剩余 N 次，约在 HH:mm 重置”，数据只来自响应头。
- 429 时保留用户问题与当前 SKU，发送按钮禁用到 `Retry-After` 倒计时结束；显示准确中文文案和手动重试入口，不自动循环重试。
- Redis FAIL_OPEN 的成功响应可显示安全的“请求保护暂时降级”说明；不显示 Redis、IP、键、脚本或连接故障。
- 既有 `isSending` 继续阻止同页并发发送。客户端不自行计算配额，也不将 `userId` 当成安全身份。
- 测试覆盖头解析、429、倒计时、恢复、降级提示、保留问题、无控制台错误与图片请求不回归。
