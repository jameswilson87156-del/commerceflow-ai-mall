# 前端中文文案规范

## 适用范围

适用于 `apps/admin-web` 与 `apps/mobile-app` 的所有真实页面、导航和共享 UI 组件。V3 授权管理端全部内部视图和 `pages.json` 中注册的全部 H5 页面；展示层可自然中文化，底层接口、字段、枚举和业务流程保持原样。

## 展示文案与技术诊断

1. 面向商家、消费者的页面标题、导航、字段、按钮和状态说明使用自然简体中文。
2. SKU、AI、API、Java 等必要技术名词可保留，必须处于清楚的中文语境。
3. 页面标签与源码变量、接口协议、数据库字段、枚举和日志标识分开。只改展示映射，不改底层值、请求参数或响应字段。
4. 内部身份、接口路径、运行模式、原始错误和技术枚举放在确有需要的系统信息或可展开诊断区域；正文先说用户看到的业务状态和下一步。
5. 不能因为中文化而隐去身份校验、只读范围、真实数据来源或错误诊断所需的信息。
6. 按钮、焦点、禁用和加载文案应与实际交互状态一致。状态不能只靠颜色区分。

## 状态文案模板

- 加载：正在加载订单信息，请稍候。
- 空数据：当前没有符合条件的订单。可以调整搜索条件后重试。
- 请求失败：暂时无法获取数据，请检查服务连接后重试。
- 未登录：请先完成管理端登录后查看此内容。
- 无权限：当前账号没有查看此内容的权限。如需访问，请联系管理员。
- 只读：当前页面仅供查看，不会修改商品、订单或库存。
- 成功：只有真实操作或真实响应确认成功后才能显示。
- 诊断：如系统实际提供，可展开查看请求编号、错误码、状态枚举或原始异常。

## 必须区分的状态

- 空列表是接口成功返回的空数据，不得写成系统异常，也不能填充虚构示例。
- 加载失败应保留重试入口与真实错误状态，不得显示空数据。
- 401、403、404、后端不可用与一般请求失败应分别表达，不能都翻成“暂无数据”。
- “本地演示”“只读”“已登录”“成功”等状态必须由当前配置、权限或请求结果决定。
- 原始技术状态可保留在诊断信息中；用户主要看到的解释使用中文。
- 运行模式名称必须来自真实配置或接口状态。OIDC 是否启用只代表身份认证配置，不能据此推断运行环境是本地演示；`MOCK`、`REAL_BACKEND`、`LOCAL_SHOWCASE` 等协议值只能在诊断内容中保留原值并配中文解释。

## 禁止事项

- 不得将 API 路径、英文枚举、内部组件名作为页面主标题。
- 不得把错误响应伪装成成功或空列表。
- 不得改变接口字段、枚举值、权限状态、运行模式或请求行为来实现翻译。
- 不得删除必要的安全提示、真实运行边界或只读说明。
- 不得把管理端和消费者页面的术语机械互换；同一功能要按对应角色表达。
