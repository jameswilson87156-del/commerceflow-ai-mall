# P6 平台范围决策

## 方案比较

| 方案 | 价值 | 成本/风险 | 决策 |
| --- | --- | --- | --- |
| A. H5 only | 最快得到一个浏览器商城 | 无法证明 UniApp 多端编译和设备适配；与项目既有 UniApp 目标不一致 | 不选 |
| B. H5 真实运行 + UniApp 多目标编译验证 | 保留可截图的主验收环境，同时证明 H5、微信小程序等编译入口可用 | 真机网络、安全区、系统返回键仍需后续验证 | **推荐** |
| C. H5 + 小程序真实运行 + Android 包 | 证据最完整 | 需要开发者工具、签名、设备、域名白名单和更多平台维护；当前项目没有这些条件 | 暂不选 |

## 最终平台策略

1. P6B 主运行环境为 H5，提供 390x844 和 430x932 的真实浏览器验收。
2. 同一 UniApp 代码执行 `npm run build:uni`，记录编译产物/日志作为跨端编译证据。
3. 微信小程序、Android 包和 iOS 包只有在具备可复现构建、真实启动和截图条件时再纳入证据；“编译成功”不等于“真机适配完成”。
4. 本轮不生成图片、不修改 manifest 以伪造平台支持、不声称已完成 iOS/Android/小程序运行。
5. 不为了平台数量加入支付、登录、推送、地图或原生插件。
