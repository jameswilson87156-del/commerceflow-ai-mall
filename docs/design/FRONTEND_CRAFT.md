# FRONTEND_CRAFT — 商城与运营台精修方向

日期：2026-09-05  
范围：既有 Admin Vue 与 H5 前端。主要重做目录页、商品详情的视觉组织，精修运营总览、导航、共享控件和数据说明。保留 API、购物车与订单合同。

## 1. 先确定产品气质

两个界面不共用一套“蓝色大圆角后台”：

- 商城：Everyday Edit，日常衣物与随身好物的编辑式陈列。暖白画布、灰绿动作、克制的中文衬线标题，以已有商品图为中心。
- 管理端：安静的运营工作台。冷灰画布、浅灰绿侧栏、深绿操作、紧凑数字和列表。清楚比装饰重要。

商城不是 Apple 商店复刻。当前商品是 T 恤和托特包，借鉴服装与生活方式网站的陈列方法更合适。Apple 只用于理解规格选择、选中反馈和购买动作层级。

## 3. 商城视觉与页面规范

### 目录页

- 画布 #FAF9F6；主文字 #292D24；次文字 #686D62；购买动作 #354C35。
- 品牌名称保持 CommerceFlow；副标 THE EVERYDAY EDIT。
- 主标题“日常，自有分寸”，使用系统可用的 Georgia / Songti / SimSun 衬线字体，不下载字体。
- 首屏是文字与实际返回的第一件商品图组成的陈列区；接口错误/空列表时不显示虚构商品。
- 去掉写死“在线”和“今天就能买到”的提示。商品目录只说明数据来自 API 或显式 Demo。
- 移除第一个列表商品强制占整行的旧规则；目录按可用宽度排列，手机两列。
- 商品图方正，价格与标题相邻；搜索、分类、排序继续基于接口返回的数据。
- 桌面商城导航置于页顶右侧；手机使用底部导航。

### 商品详情

- 桌面最大内容宽度 1200px；左图片 / 右商品信息与规格。不是把 560px 的手机卡片放在桌面中间。
- 手机按图片 → 标题价格 → 规格 → 购买说明 → 商品助手排列。
- 图片用仓库现有资产，不生成不存在的商品；SKU 图片随选择切换。
- 规格为两列紧凑选项，保留颜色、尺码、库存状态和 aria-pressed。零库存选项不可点击。
- 从每张规格卡移除冗长 SKU 编码，技术编号仍可在商品事实中查看。
- 主按钮深灰绿、次按钮描边，弱化胶囊圆角和蓝色阴影。
- 加购物车与立即购买仍调用原有后端接口，不修改业务写入逻辑。
- AI 入口用问答符号和文字，不依赖通用星光符号装饰。

### 其他商城页面

共享按钮、画布、基础面板、底部导航跟随主题。购物车、订单与 AI 页做响应式和状态回归，不在本轮重写其业务流程；这些页面的完整信息架构升级不是本轮“已全部重做”的范围。

## 4. 管理端规范

- 侧栏宽 224px、底色 #F0F3F1；选中项 #DFEAE4；主动作 #245B49。
- 导航替换几何占位图形为统一 24px viewBox 的线性 SVG 图标，无第三方图标依赖。
- 指标形成一条连续的事实摘要，而不是五张各带阴影的卡片；数字使用 tabular-nums。
- 订单、库存保持列表，不新增无数据来源的趋势线或商业 KPI。
- 数据说明改成 details。普通说明默认收起；红色/黄色风险说明默认展开。
- 系统与数据边界独立折叠，仍能查看全部运行信息。
- 移除“Java API 在线”的写死结论，改为“连接结果以各页面请求为准”。

## 5. 代码组织与不破坏项

- Admin：apps/admin-web/src/craft.css，由 main.ts 在旧 style.css 后导入。
- H5：apps/mobile-app/src/styles/craft.css，由 main.ts 导入。
- 页面精修采用明确根类作用域，避免跨 Admin/H5 污染。
- 仓库旧样式包含多轮设计叠加；本轮保留已有未提交修改，将新规则集中。后续整理应按组件逐步迁移，不用大规模覆盖丢弃旧工作。
- 不新增依赖、生产 Mock、远程字体、商业图片、API Key 或网络服务。
- 不修改真实/Demo 数据切换，不把测试 fixture 合并进产品。

## 6. 测试边界

- Admin：npm run build（含 vue-tsc）、npm test。
- H5：npm run build、npm test。H5 build 不等同于 APP/小程序运行验收。
- 浏览器：D:/workhome/frontend-craft-qa.cjs；产物 D:/workhome/frontend-craft-20260905。
- Admin/H5 的成功态使用脚本内合成 API fixture，截图有“视觉验收 · 合成接口样例”水印。它只证明前端渲染和交互，不证明真实数据库、真实身份或部署联调。
- 验证正常、错误、空状态，搜索与清除筛选，SKU 选择和缺货禁用，桌面/手机及中间断点。
- 不自动调用真实付费模型、不改 deploy 配置、不执行 commit/push/deploy。

本轮形成的是可运行的视觉精修版本，不是公网部署通过证明。真实 IdP、MySQL/Redis、DeepSeek、支付边界与部署配置仍按独立审查结果验收。
