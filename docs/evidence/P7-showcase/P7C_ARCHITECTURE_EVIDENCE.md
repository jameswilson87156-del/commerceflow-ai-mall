# P7C Architecture Evidence

`docs/architecture/` documents the actual Vue Admin, UniApp H5, Spring Boot modular monolith, MySQL, JDBC transaction path, MyBatis read model, FastAPI, deterministic Mock Provider, and Redis Lua limiter.

It deliberately does not depict microservices, API gateway, Kafka, Elasticsearch, vector databases, Kubernetes, payment, logistics, or an authentication center. Order, AI, and Redis documents make their storage and ownership boundaries explicit.
