## Rules

- The listed CommerceFlow originals are the only product images permitted for P3.1 runtime work.
- Reference-project images, screenshots, brand marks, and icons remain research-only and must not be copied into `public`, `src/assets`, screenshots, or documentation presented as CommerceFlow runtime evidence.
- P3.1 must store a path snapshot selected from the approved local assets; it does not download or proxy remote images.
