# CommerceFlow Product SKU Design Sources

## Reference Boundary

`target-page.png` is an AI-generated P2 visual reference for the Product and SKU page. It is not a real runtime screenshot, test result, or API evidence. The application must not use it as a page background.

## Product Assets

The five product PNG files are original AI-generated product assets created for the CommerceFlow Showcase. They contain no third-party brands, logos, or watermarks.

They may be used for CommerceFlow product-list, product-detail, SKU, cart, and order demonstrations. They do not represent real products, merchants, or transactions, and they are not third-party commercial assets.

## Runtime Use

Real runtime screenshots remain in the repository `screenshots/` directory. When the Product and SKU page consumes these images at runtime, the assets must be copied into a formal frontend assets directory rather than referenced directly from this documentation directory.
