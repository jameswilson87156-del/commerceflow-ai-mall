# Resume Bullets: Java Full-Stack

- Built a Java 17 + Spring Boot 3 e-commerce backend with Product, SKU, Inventory, Cart, Order, Flyway migrations, OpenAPI, and demo data.
- Implemented a transactional order path using `BigDecimal`, product/SKU/price snapshots, `@Transactional`, guarded inventory deduction, MySQL idempotency constraints, and rollback tests.
- Connected Vue 3 admin and UniApp user flows to local APIs for catalog, cart, checkout, orders, AI customer service, and operational trace review.

Accuracy note: showcase implementation was substantially Codex-assisted; ownership verification is intentionally separate.
